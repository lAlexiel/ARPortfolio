# Add artwork here

Upload numbered images into this folder in GitHub, for example `08.jpg`, `09.png`, `10.webp`. Images appear in numerical order after the Pages workflow finishes. JPG, JPEG, PNG, WebP, GIF, and AVIF are supported.

Do not upload only to a local folder if you want the live website to change; upload or commit and push to GitHub.

Names can include descriptions: `08-new-character.jpg`. No HTML edits or metadata entries are required. A new file without metadata is shown as `Artwork 08` in Illustrations. Optional titles, alt text, and categories go in `content/gallery-meta.json`.

Categories: `Portraits`, `Illustrations`, `Monochrome`, `Sketches`, and `Posters`. The site translates their labels into English and Spanish.

`thumbnails/` contains smaller previews, not extra artworks. The optional `thumbnail` field names a file in this subfolder. When updating an image, replace its preview too or remove that field. `sourceName` records an imported drawing's original filename.
